Генеративный ИИ использован для заполнения поля CONTRIBUTIONS.md

## Настройка CI для бэкенда

- Участник: M1
- Задача: Настроить CI в GitHub.
- Использование ИИ: ChatGPT предложил черновик workflow с Java 21, PostgreSQL 17 и запуском Gradle.
- В проект вошло: workflow, который запускает `./gradlew --no-daemon build` для pull request в `main` и при push в `main`.
- Проверка человеком: просмотрел конфигурацию, проверил работоспособность локально при собирающемся проекте, ошибку при ошибке компиляции в проекте
- Связанный результат: [конфигурация CI](.github/workflows/ci.yml)
