### D-06. Регистрация и вход по паролю

**Контекст:** При регистрации пользователь указывает почту и пароль. До подтверждения почты нельзя разрешать вход в аккаунт. После подтверждения пользователь входит по почте и паролю.

**Решение:**

- При регистрации сервер нормализует почту, сохраняет хеш пароля и статус неподтвержденного аккаунта. Пароль в открытом виде не хранится.
- Повторная регистрация неподтвержденного адреса не создает второй аккаунт и повторяет отправку кода с ограничением частоты. Для подтвержденного адреса новый аккаунт также не создается. Ответ регистрации не раскрывает, существует ли аккаунт.
- Код из письма используется один раз. После правильного кода аккаунт становится подтвержденным.
- После подтверждения вход выполняется по почте и паролю. Сервер сравнивает пароль с сохраненным хешем.
- При смене пароля пользователь указывает текущий и новый пароль. После смены старый пароль больше не подходит.

**Обоснование:** Код подтверждает владение почтой только при регистрации. Повторная отправка кода позволяет владельцу завершить ранее начатую регистрацию, не создавая дубликат аккаунта. Одинаковый ответ не позволяет проверить существование аккаунта по адресу. Хеш пароля позволяет не хранить пароль в открытом виде. Проверка текущего пароля защищает смену пароля от постороннего пользователя.

**Связанные угрозы:** [T-01](../threat-model/threats/T-01.md).

**Связанные требования:** [SR-AUTH-01](../security-requirements/auth/SR-AUTH-01.md), [SR-AUTH-03](../security-requirements/auth/SR-AUTH-03.md), [SR-AUTH-06](../security-requirements/auth/SR-AUTH-06.md).

**Будущая проверка:**

- **Условие:** Пользователь зарегистрировался и получил код на почту.
- **Действие:** Повторить регистрацию с тем же адресом, попытаться войти до подтверждения, затем подтвердить почту и войти по паролю. После этого сменить пароль.
- **Ожидаемый результат:** Повторная регистрация не создает второй аккаунт и не раскрывает его состояние. До подтверждения вход запрещен. После подтверждения правильный пароль позволяет войти. После смены новый пароль работает, старый больше не работает.

**Ограничения и последствия:** Решение не защищает аккаунт, если злоумышленник получил доступ к почте или узнал пароль пользователя. Ограничение частоты не должно мешать владельцу запросить новый код после истечения предыдущего.
