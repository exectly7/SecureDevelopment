# T-01

## Сценарий угрозы

Пользователь `UNAUTHORIZED` вводит адрес электронной почты другого клиента. Сервер предоставляет доступ к учетной записи до успешной проверки кода из письма и принимает пользователя за владельца аккаунта.

## Последствия

Посторонний пользователь получает сведения об устройствах и ремонте клиента. Он также может подтвердить или отклонить ремонт от имени клиента.

## Граница или точка входа

Форма регистрации или входа и API проверки кода на границе между браузером и сервером.

## Приоритет

High

Для попытки входа достаточно знать адрес электронной почты клиента. Если сервер не требует успешного подтверждения кода, посторонний пользователь получает все доступные клиенту данные и действия.
