# T-04

## Сценарий угрозы

Авторизованный клиент подставляет идентификатор чужой заявки в запросе. Сервер проверяет только наличие авторизации и возвращает сведения о чужом устройстве, диагностике, стоимости или состоянии ремонта.

## Последствия

Клиент получает персональные, технические и финансовые сведения другого клиента. Перебор идентификаторов также позволяет определить наличие чужих заявок.

## Граница или точка входа

API просмотра заявки по идентификатору на границе между браузером и сервером.

## Приоритет

High

Любой клиент может изменить идентификатор в запросе. Ошибка проверки владельца приводит к прямому раскрытию данных другого клиента.
