# T-02

## Сценарий угрозы

Пользователь с ролью `CLIENT`, `ADMIN` или `ENGINEER` напрямую отправляет запрос к API выдачи прав и указывает адрес электронной почты и новую роль. Сервер не проверяет, что запрос отправил пользователь с ролью `SUPERUSER`, и выдает роль `ADMIN` или `ENGINEER`.

## Последствия

Пользователь без полномочий получает доступ к данным клиентов и заявок. В зависимости от полученной роли он может создавать заявки или изменять сведения о ремонте.

## Граница или точка входа

API выдачи прав на границе между браузером и сервером.

## Приоритет

High

Получение служебной роли открывает доступ сразу к нескольким критичным операциям и данным. Прямой запрос к API позволяет обойти отсутствие функции выдачи прав в интерфейсе обычного пользователя.
