# T-08

## Сценарий угрозы

Пользователь с ролью `CLIENT` просматривает предложение ремонта, после чего пользователь с ролью `ENGINEER` изменяет состав работ, стоимость или срок. Сервер принимает ранее отправленное согласие клиента и применяет его к новым условиям, которые клиент не видел.

## Последствия

Сервис начинает ремонт на условиях, с которыми клиент не соглашался. Клиенту могут выполнить лишние работы или выставить другую стоимость.

## Граница или точка входа

API просмотра условий, изменения ремонта и подтверждения решения. Сценарий затрагивает обработку нескольких запросов и запись состояния в базу данных.

## Приоритет

High

Угроза возникает в основном сценарии согласования ремонта. Ее последствием может стать выполнение и оплата работ без действительного согласия клиента.
