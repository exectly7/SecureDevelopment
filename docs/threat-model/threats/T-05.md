# T-05

## Сценарий угрозы

Клиент, инженер или неавторизованный пользователь напрямую обращается к API реестра клиентов. Сервер проверяет только наличие аккаунта или скрывает раздел в интерфейсе, но не проверяет роль пользователя на каждом запросе.

## Последствия

Пользователь без полномочий получает список клиентов, их контактные данные или сведения об отдельных клиентах.

## Граница или точка входа

API поиска и просмотра клиентов на границе между браузером и сервером.

## Связанные требования

- [SR-CLIENT-01](../../security-requirements/client/SR-CLIENT-01.md)
- [SR-AUTH-04](../../security-requirements/auth/SR-AUTH-04.md)

## Приоритет

High

Реестр содержит персональные и контактные данные. Ограничение только в интерфейсе легко обойти прямым запросом к API.
