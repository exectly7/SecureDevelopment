# T-10

## Сценарий угрозы

Пользователь получает или подбирает идентификатор фотографии в S3-совместимом хранилище. Хранилище или сервер возвращает файл без проверки владельца заявки и полномочий пользователя.

## Последствия

Пользователь получает фотографии чужого устройства. На фотографиях могут быть видны серийные номера, состояние устройства и другие сведения клиента.

## Граница или точка входа

API получения фотографий и взаимодействие сервера с внешним S3-совместимым хранилищем.

## Связанные требования

Подходящее требование отсутствует. Если фотографии останутся в составе продукта, к S04 необходимо добавить требование на доступ к ним только владельцу заявки и уполномоченным сотрудникам.

## Приоритет

Medium

Фотографии могут содержать чувствительные сведения, но их хранение указано как необязательная функция. Если команда включит фотографии в первую версию, приоритет угрозы нужно пересмотреть.
