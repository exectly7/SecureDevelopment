# T-06

## Сценарий угрозы

Во время создания заявки происходит ошибка сохранения клиента, устройства или связи между ними. Сервер сохраняет уже выполненную часть операции и оставляет заявку без владельца, без устройства или с неправильным клиентом.

## Последствия

В системе появляется неполная или ошибочная заявка. Данные об устройстве могут стать доступны другому клиенту, а сотрудники могут начать работу не с тем устройством.

## Граница или точка входа

Форма приема устройства, серверное API и операции записи в базу данных.

## Приоритет

Medium

Сбой возможен при обычной работе системы и нарушает учет устройств. Для реализации сценария не требуется намеренное действие пользователя, но ошибка может быть обнаружена сотрудником до начала ремонта.
