# SR-CLIENT-06

## Утверждение

Изменять связь заявки с клиентом может только авторизованный админ и только до передачи результатов диагностики клиенту.

## Критерий приемки

- Сервис сохраняет новую связь с существующим клиентом, если авторизованный админ исправляет владельца заявки до передачи результатов диагностики клиенту.
- Сервис возвращает ошибку доступа и не изменяет владельца, если клиент или инженер пытается изменить связь заявки с клиентом.
- Сервис отклоняет операцию и не изменяет владельца, если авторизованный админ пытается исправить связь после передачи результатов диагностики клиенту.
- Сервис возвращает ошибку аутентификации и не изменяет владельца, если запрос отправляет неавторизованный пользователь.

## Внутреннее обоснование

- Актив: принадлежность заявки, сведения об устройстве и решение клиента о ремонте.
- Роль: админ, клиент, инженер, неавторизованный пользователь.
- Взаимодействие: исправление связи существующей заявки с клиентом.
- Недопустимое событие: заявка перепривязывается посторонним пользователем или после того, как клиент получил условия ремонта.

## Внешний источник

Не использован.

## Приоритет

High

Несанкционированная или поздняя перепривязка заявки может раскрыть данные другому клиенту либо связать его решение с чужим устройством.
