# SR-CLIENT-02

## Утверждение

Создать заявку можно только для существующего клиента с подтвержденным аккаунтом. Админ не создает аккаунт клиента при приеме устройства.

## Критерий приемки

- Сервис позволяет продолжить создание заявки, если авторизованный админ указал существующий подтвержденный аккаунт клиента.
- Сервис отклоняет операцию и не создает аккаунт или заявку, если указанный аккаунт не существует или не подтвержден.
- Сервис возвращает ошибку доступа и не создает заявку, если клиент, инженер или суперпользователь без роли `ADMIN` пытается создать ее вместо админа.
- Сервис возвращает ошибку аутентификации и не создает заявку, если запрос отправляет неавторизованный пользователь.

## Внутреннее обоснование

- Актив: реестр клиентов, подтвержденные аккаунты и содержащиеся в них персональные данные.
- Роль: админ, клиент, инженер, неавторизованный пользователь.
- Взаимодействие: выбор клиента при создании заявки на ремонт.
- Недопустимое событие: заявка создается для несуществующего или неподтвержденного клиента либо админ создает аккаунт от имени клиента.

## Внешний источник

Не использован.

## Приоритет

Medium

Создание заявки без подтвержденного аккаунта может привести к ошибочной связи клиента с заявкой и передаче данных постороннему лицу.
