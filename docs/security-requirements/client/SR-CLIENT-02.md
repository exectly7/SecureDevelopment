# SR-CLIENT-02

## Утверждение

Создавать записи новых клиентов может только авторизованный админ.

## Критерий приемки

- Сервис создает запись клиента, если авторизованный админ отправляет корректные данные нового клиента.
- Сервис возвращает ошибку доступа и не создает запись, если клиент или инженер пытается создать запись клиента.
- Сервис возвращает ошибку аутентификации и не создает запись, если неавторизованный пользователь пытается создать запись клиента.

## Внутреннее обоснование

- Актив: реестр клиентов и содержащиеся в нем персональные данные.
- Роль: админ, клиент, инженер, неавторизованный пользователь.
- Взаимодействие: создание записи клиента при приеме устройства.
- Недопустимое событие: пользователь без полномочий добавляет ложную или несанкционированную запись клиента.

## Внешний источник

Не использован.

## Приоритет

Medium

Несанкционированное создание записей нарушает целостность реестра и может привести к ошибочной связи клиента с заявкой.
