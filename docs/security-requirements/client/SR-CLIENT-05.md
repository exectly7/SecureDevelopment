# SR-CLIENT-05

## Утверждение

Клиент, принятое устройство и заявка должны сохраняться согласованно, без появления неполной заявки при ошибке создания одной из обязательных частей.

## Критерий приемки

- Сервис создает полную заявку, связанную с устройством и владельцем, если авторизованный админ указывает корректные данные и все обязательные сведения успешно сохраняются.
- Сервис не оставляет заявку без устройства или владельца и сообщает админу об ошибке, если не удалось сохранить клиента, устройство, заявку или связь между ними.
- Сервис не показывает клиенту частично созданную заявку после неуспешной операции.

## Внутреннее обоснование

- Актив: целостность реестра клиентов, устройств и заявок.
- Роль: админ, клиент.
- Взаимодействие: сохранение связанных данных при приеме устройства.
- Недопустимое событие: в системе появляется заявка без устройства, без владельца или с незавершенными связями.

## Внешний источник

Не использован.

## Приоритет

High

Неполные записи нарушают учет принятых устройств и могут связать сведения о ремонте не с тем клиентом.
