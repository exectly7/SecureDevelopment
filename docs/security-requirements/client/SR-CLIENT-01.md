# SR-CLIENT-01

## Утверждение

Искать и просматривать записи клиентов может только авторизованный админ.

## Критерий приемки

- Сервис возвращает данные, если авторизованный админ запрашивает список клиентов, выполняет поиск или открывает существующую запись клиента.
- Сервис возвращает ошибку доступа, если клиент или инженер пытается получить список клиентов, выполнить поиск или открыть запись клиента.
- Сервис возвращает ошибку аутентификации, если неавторизованный пользователь обращается к реестру клиентов.

## Внутреннее обоснование

- Актив: персональные и контактные данные клиентов.
- Роль: админ, клиент, инженер, неавторизованный пользователь.
- Взаимодействие: поиск и просмотр записей клиентов.
- Недопустимое событие: пользователь без полномочий получает доступ к реестру клиентов.

## Внешний источник

Не использован.

## Приоритет

High

Несанкционированный доступ к реестру приводит к раскрытию персональных данных клиентов.
