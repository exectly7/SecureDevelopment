# SR-AUTH-01

## Утверждение
Аккаунт можно использовать только после подтверждения электронной почты кодом из письма.

## Критерий приёмки
- Пользователь вводит правильный код из письма, аккаунт подтверждается.
- Пользователь вводит неверный, просроченный или уже использованный код, аккаунт остается неподтвержденным.
- Вход в неподтвержденный аккаунт не выполняется.
- Повторная регистрация неподтвержденного аккаунта не создает второй аккаунт и безопасно повторяет отправку кода на тот же адрес с ограничением частоты.

## Внутреннее обоснование
- Актив: аккаунт пользователя и связанные с ним данные.
- Роль: пользователь, неавторизованный пользователь.
- Взаимодействие: регистрация и подтверждение почты.
- Недопустимое событие: использование аккаунта без подтверждения почты.

## Внешний источник
Не использован.

## Приоритет
High

Без подтверждения почты посторонний человек может зарегистрировать аккаунт на чужой адрес.
