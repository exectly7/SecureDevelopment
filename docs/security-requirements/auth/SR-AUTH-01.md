# SR-AUTH-01

## Утверждение
Аккаунт не считается зарегестрированным при отстутствии подтверждения электронной почты.

## Критерий приёмки
При попытке совершения действий требующих авторизации с аккаунта с неподтвержденной электронной почтой запрос возвращает ошибку.

## Внутреннее обоснование
- Актив: электронная почта.
- Роль: пользователь.
- Взаимодействие: регистрация аккаунта.
- Недопустимое событие: создание аккаунта на чужой адрес электронной почты.

## Внешний источник
Не использован.

## Приоритет
Medium

Может забрать возможность регистрации у потенциального клиента из-за занятости электронного почтового адреса.
