# SR-AUTH-06

## Утверждение
Получить доступ к учетной записи может только человек знающий пароль и адрес электронной почты.

## Критерий приёмки
При попытке входа с неверными данными вход не производится.

## Внутреннее обоснование
- Актив: доступ к учетной записи
- Роль: пользователь, админ, инженер
- Взаимодействие: вход в аккаунт
- Недопустимое событие: вход в аккаунт не принадлежащий входящему

## Внешний источник
Не использован.

## Приоритет
High

Недопустимо давать доступ к произвольной учетной записи из-за возможности компрометации данных.
