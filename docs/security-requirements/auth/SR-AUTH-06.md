# SR-AUTH-06

## Утверждение
Войти в подтвержденный аккаунт можно только по правильной электронной почте и паролю.

## Критерий приёмки
- Пользователь вводит правильную почту и пароль, вход выполняется.
- Пользователь вводит неправильную почту или пароль, вход не выполняется.
- Пользователь вводит правильные данные неподтвержденного аккаунта, вход не выполняется.
- Ответ при неправильной почте и неправильном пароле выглядит одинаково.

## Внутреннее обоснование
- Актив: аккаунт и доступные ему данные.
- Роль: пользователь, админ, инженер, суперпользователь.
- Взаимодействие: вход по электронной почте и паролю.
- Недопустимое событие: вход с неправильными данными или в неподтвержденный аккаунт.

## Внешний источник
Не использован.

## Приоритет
High

Доступ к чужому аккаунту может привести к раскрытию и изменению данных.
