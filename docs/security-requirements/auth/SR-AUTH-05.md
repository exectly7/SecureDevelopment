# SR-AUTH-05

## Утверждение
Админ не может изменять, создавать и удалять результаты диагностики, список необходимых услуг и компонентов, назначенные сроки ремонта.

## Критерий приёмки
Попытка изменить, создать или удалить результаты диагностики, список необходимых услуг и компонентов, назначенные сроки ремонта учетной записью с ролью админ не изменяет, создает или удаляет соответствующую информацию. При попытке совершить те же действия с учетной записи инженера информация обновляется корректно.

## Внутреннее обоснование
- Актив: целостность данных сервиса.
- Роль: админ, инженер.
- Взаимодействие: создание, изменение, удаление информации о диагностике.
- Недопустимое событие: приведение информации о диагностике в некорректное состояние.

## Внешний источник
Не использован.

## Приоритет
High

Некорректная работа сервиса, несанкционнированный доступ к данным.
