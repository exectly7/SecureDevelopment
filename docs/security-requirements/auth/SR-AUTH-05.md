# SR-AUTH-05

## Утверждение
Изменять результаты диагностики и условия ремонта до решения клиента может только пользователь с ролью `ENGINEER`. Роли `ADMIN` и `SUPERUSER` не дают этих полномочий.

## Критерий приёмки
- Пользователь с ролью `ENGINEER` изменяет результаты диагностики или условия ремонта до решения клиента, сервис выполняет операцию.
- Пользователь с ролью `ADMIN` либо `SUPERUSER` без роли `ENGINEER` пытается изменить результаты диагностики или условия ремонта, сервис возвращает ошибку доступа и не изменяет данные.
- Пользователь с ролью `ENGINEER` пытается изменить результаты диагностики или условия ремонта после согласия или отказа клиента, сервис возвращает ошибку текущего состояния и не изменяет данные.

## Внутреннее обоснование
- Актив: целостность данных сервиса.
- Роль: суперпользователь, админ, инженер.
- Взаимодействие: создание, изменение, удаление информации о диагностике.
- Недопустимое событие: приведение информации о диагностике в некорректное состояние.

## Внешний источник
Не использован.

## Приоритет
High

Некорректная работа сервиса, несанкционнированный доступ к данным.
