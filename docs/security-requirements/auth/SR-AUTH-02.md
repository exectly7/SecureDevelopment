# SR-AUTH-02

## Утверждение
Выдавать и отзывать роли `ADMIN` и `ENGINEER` может только пользователь с ролью `SUPERUSER`.

## Критерий приёмки
- Пользователь с ролью `SUPERUSER` выдает или отзывает роль `ADMIN` либо `ENGINEER`, сервис выполняет операцию.
- Пользователь с ролью `CLIENT`, `ADMIN` или `ENGINEER` пытается выдать или отозвать служебную роль, сервис возвращает ошибку доступа и не изменяет роли.
- Неаутентифицированный пользователь пытается выдать или отозвать служебную роль, сервис возвращает ошибку аутентификации и не изменяет роли.

## Внутреннее обоснование
- Актив: права доступа к сервису.
- Роль: суперпользователь, админ, инженер, клиент, неавторизованный пользователь.
- Взаимодействие: выдача и отзыв служебных ролей.
- Недопустимое событие: пользователь без роли `SUPERUSER` выдает или отзывает служебные права.
 
## Внешний источник
Не использован.

## Приоритет
High

Несанкционированная выдача служебной роли открывает доступ к персональным данным и операциям над заявками.
