# SR-AUTH-02

## Утверждение
Аккаунты с ролями админ/инженер можно создать только от существующего админа.

## Критерий приёмки
При попытке получения ролей админ/инженер имея роль пользователь/инженер роль не выдается. При попытке выдачи ролей админ/инженер имея роль админ роль выдается.

## Внутреннее обоснование
- Актив: права доступа к сервису.
- Роль: админ, инженер, клиент.
- Взаимодействие: регистрация админа/инженера.
- Недопустимое событие: регистрация админа/инженера не имея прав.
 
## Внешний источник
Не использован.

## Приоритет
High

Несанкционированный доступ в сервис.
