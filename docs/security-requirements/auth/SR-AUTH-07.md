# SR-AUTH-07

## Утверждение
Уволенные сотрудники не должны иметь доступ к служебной информации.

## Критерий приёмки
После увольнения сотрудника его учетная запись теряет права на чтение и изменение ранее доступной ему информации. Активная учетная запись сотрудника имеет доступ к чтению и изменению этой информации.

## Внутреннее обоснование
- Актив: служебная информация.
- Роль: админ, инженер.
- Взаимодействие: все.
- Недопустимое событие: получение доступа неактивной учетной записью.

## Внешний источник
Не использован.

## Приоритет
High

Служебная информация должна быть доступна только действующим сотрудникам.
