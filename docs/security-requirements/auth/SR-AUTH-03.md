# SR-AUTH-03

## Утверждение
На каждый нормализованный электронный почтовый адрес можно создать только одну учетную запись независимо от регистра символов.

## Критерий приёмки
- Пользователь регистрируется на свободный адрес электронной почты, сервис нормализует адрес, создает неподтвержденную учетную запись и возвращает нейтральный ответ.
- Пользователь повторно регистрируется на адрес неподтвержденной учетной записи, сервис не создает вторую учетную запись и повторяет отправку кода с ограничением частоты.
- Пользователь регистрируется на адрес подтвержденной учетной записи, сервис не создает новую учетную запись.
- Ответ регистрации выглядит одинаково для свободного адреса, неподтвержденной и подтвержденной учетной записи.
- Адреса, которые отличаются только регистром символов, считаются одним адресом и не создают разные учетные записи.

## Внутреннее обоснование
- Актив: целостность данных сервиса.
- Роль: пользователь, неавторизованный пользователь.
- Взаимодействие: регистрация учетной записи.
- Недопустимое событие: две учетные записи используют один электронный почтовый адрес либо незавершенная регистрация блокирует владельцу возможность подтвердить адрес.

## Внешний источник
Не использован.

## Приоритет
Medium

Нарушение целостности данных и корректной работы сервиса.
