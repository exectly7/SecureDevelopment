# SR-AUTH-03

## Утверждение
На каждый электронный почтовый адрес можно создать только одну учетную запись.

## Критерий приёмки
- Пользователь регистрируется на свободный адрес электронной почты, учетная запись создается.
- Пользователь пытается зарегистрироваться на адрес, который уже используется, сервис возвращает ошибку и не создает новую учетную запись.

## Внутреннее обоснование
- Актив: целостность данных сервиса.
- Роль: пользователь, неавторизованный пользователь.
- Взаимодействие: регистрация учетной записи.
- Недопустимое событие: две учетные записи используют один электронный почтовый адрес.

## Внешний источник
Не использован.

## Приоритет
Medium

Нарушение целостности данных и корректной работы сервиса.
