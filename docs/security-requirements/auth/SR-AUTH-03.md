# SR-AUTH-03

## Утверждение
На каждый электронный почтовый адрес можно создать только одну учетную запись.

## Критерий приёмки
Попытка регистрации новой учетной записи на уже используемый электронный почтовый адрес другой учетной записью отклоняется и учетная запись не создается. Попытка смены адреса электронной почты на уже использующийся отклоняется и адрес остается прежним.

## Внутреннее обоснование
- Актив: целостность данных сервиса.
- Роль: пользователь, админ, инженер.
- Взаимодействие: регистрация учетной записи.
- Недопустимое событие: две учетные записи используют один электронный почтовый адрес.

## Внешний источник
Не использован.

## Приоритет
Medium

Нарушение целостности данных и корректной работы сервиса.
