# SR-AUTH-04

## Утверждение
Пользователь должен иметь доступ только к информации о собственных запросах на ремонт.

## Критерий приёмки
При попытке получения доступа к чужому запросу на ремонт запрос возвращает ошибку, при попытке получения доступа к своему запросу на ремонт запрос возвращает необходимую информацию.

## Внутреннее обоснование
- Актив: информация об устройстве.
- Роль: пользователь.
- Взаимодействие: запрос информации.
- Недопустимое событие: получение информации о чужом устройстве.

## Внешний источник
Не использован.

## Приоритет
High

Получение чужих персональных данных недопустимо.
