# SR-REPAIR-08

## Утверждение
Изменять состояние любой заявки может только аутентифицированный пользователь с ролью `ENGINEER`.

## Критерий приёмки
- Пользователь с ролью `ENGINEER` запрашивает допустимое изменение состояния существующей заявки → сервис выполняет переход.
- Пользователь с ролью `CLIENT` или `EMPLOYEE` пытается изменить состояние заявки → сервис возвращает ошибку доступа.
- Неаутентифицированный пользователь пытается изменить состояние заявки → сервис возвращает ошибку аутентификации.

## Внутреннее обоснование
- Актив: состояние заявки и сведения о ходе ремонта.
- Роль: инженер, клиент, сотрудник.
- Взаимодействие: изменение состояния заявки.
- Недопустимое событие: пользователь без роли `ENGINEER` изменяет этап обработки заявки.

## Внешний источник
Не использован.

## Приоритет
Medium

Несанкционированное изменение состояния нарушает рабочий процесс и может передать клиенту неверную информацию, но не предоставляет доступ к изменению результатов или условий ремонта.
