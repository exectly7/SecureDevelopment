# SR-REPAIR-08

## Утверждение
Служебные переходы состояния заявки может выполнять только аутентифицированный пользователь с ролью `ENGINEER`. Решение или ранняя отмена владельца запускают только предусмотренные для клиента автоматические переходы.

## Критерий приёмки
- Пользователь с ролью `ENGINEER` запрашивает допустимый служебный переход существующей заявки: сервис выполняет переход.
- Пользователь с ролью `CLIENT` подтверждает, отклоняет или рано отменяет собственную заявку в допустимом состоянии: сервис выполняет соответствующий автоматический переход.
- Пользователь с ролью `CLIENT` пытается запросить другой переход состояния: сервис возвращает ошибку доступа.
- Пользователь с ролью `ADMIN` либо `SUPERUSER` без роли `ENGINEER` пытается выполнить служебный переход состояния заявки: сервис возвращает ошибку доступа.
- Неаутентифицированный пользователь пытается изменить состояние заявки: сервис возвращает ошибку аутентификации.

## Внутреннее обоснование
- Актив: состояние заявки и сведения о ходе ремонта.
- Роль: инженер, клиент, сотрудник.
- Взаимодействие: изменение состояния заявки.
- Недопустимое событие: пользователь выполняет переход, который не разрешен его ролью и текущим состоянием заявки.

## Внешний источник
Не использован.

## Приоритет
Medium

Несанкционированное изменение состояния нарушает рабочий процесс и может передать клиенту неверную информацию, но не предоставляет доступ к изменению результатов или условий ремонта.
