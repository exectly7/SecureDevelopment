# SR-REPAIR-07

## Утверждение
После подтверждения ремонта клиентом пользователь с ролью `ENGINEER` не может изменять состав услуг, необходимые компоненты, стоимость и ожидаемое время ремонта.

## Критерий приёмки
- Клиент ещё не подтвердил ремонт → пользователь с ролью `ENGINEER` может изменять услуги, компоненты, стоимость и ожидаемое время ремонта.
- Клиент подтвердил ремонт → при попытке пользователя с ролью `ENGINEER` изменить услуги, компоненты, стоимость или ожидаемое время сервис возвращает ошибку текущего состояния заявки.

## Внутреннее обоснование
- Актив: подтверждённые клиентом состав и условия ремонта.
- Роль: клиент, инженер.
- Взаимодействие: подтверждение ремонта и последующее изменение его условий.
- Недопустимое событие: после подтверждения клиента условия ремонта изменяются без его согласия.

## Внешний источник
Не использован.

## Приоритет
High

Изменение подтверждённых условий приводит к выполнению работ или начислению стоимости, на которые клиент не соглашался.
