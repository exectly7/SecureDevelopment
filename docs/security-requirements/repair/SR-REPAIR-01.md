# SR-REPAIR-01

## Утверждение
Любой аутентифицированный пользователь с ролью `ENGINEER` может просматривать очередь диагностики и открывать любую заявку на ремонт. Пользователи с ролями `CLIENT` и `EMPLOYEE` не имеют доступа к очереди диагностики.

## Критерий приёмки
- Пользователь с ролью `ENGINEER` запрашивает очередь диагностики или открывает существующую заявку → сервис возвращает запрошенные данные.
- Пользователь с ролью `CLIENT` или `EMPLOYEE` запрашивает очередь диагностики → сервис возвращает ошибку доступа.
- Неаутентифицированный пользователь запрашивает очередь диагностики → сервис возвращает ошибку аутентификации.

## Внутреннее обоснование
- Актив: очередь диагностики и сведения о принятых устройствах.
- Роль: инженер, клиент, сотрудник.
- Взаимодействие: просмотр очереди диагностики и открытие заявки.
- Недопустимое событие: пользователь без роли `ENGINEER` получает доступ к очереди диагностики.

## Внешний источник
Не использован.

## Приоритет
Medium

Раскрытие очереди нарушает конфиденциальность служебной информации, но само по себе не позволяет изменить результаты диагностики или условия ремонта.
