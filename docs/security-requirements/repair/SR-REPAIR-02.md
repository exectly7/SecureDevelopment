# SR-REPAIR-02

## Утверждение
Изменять результаты диагностики любой заявки может только аутентифицированный пользователь с ролью `ENGINEER`.

## Критерий приёмки
- Пользователь с ролью `ENGINEER` изменяет результат диагностики существующей заявки → сервис выполняет операцию.
- Пользователь с ролью `CLIENT` или `EMPLOYEE` пытается изменить результат диагностики → сервис возвращает ошибку доступа.
- Неаутентифицированный пользователь пытается изменить результат диагностики → сервис возвращает ошибку аутентификации.

## Внутреннее обоснование
- Актив: результат диагностики устройства.
- Роль: инженер, клиент, сотрудник.
- Взаимодействие: изменение результата диагностики.
- Недопустимое событие: пользователь без роли `ENGINEER` изменяет результат диагностики.

## Внешний источник
Не использован.

## Приоритет
High

Подмена результата диагностики может привести к неверному ремонту и передаче клиенту ложной информации.
