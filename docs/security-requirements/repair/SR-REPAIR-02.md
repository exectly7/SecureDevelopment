# SR-REPAIR-02

## Утверждение
Изменять результаты диагностики до фиксации согласия или отказа клиента может только аутентифицированный пользователь с ролью `ENGINEER`.

## Критерий приёмки
- Пользователь с ролью `ENGINEER` изменяет результат диагностики до решения клиента: сервис выполняет операцию и увеличивает версию предложения.
- Пользователь с ролью `ENGINEER` пытается изменить результат диагностики после согласия или отказа клиента: сервис возвращает ошибку текущего состояния и не изменяет данные.
- Пользователь с ролью `CLIENT`, `ADMIN` или `SUPERUSER` без роли `ENGINEER` пытается изменить результат диагностики: сервис возвращает ошибку доступа.
- Неаутентифицированный пользователь пытается изменить результат диагностики: сервис возвращает ошибку аутентификации.

## Внутреннее обоснование
- Актив: результат диагностики устройства.
- Роль: инженер, клиент, сотрудник.
- Взаимодействие: изменение результата диагностики.
- Недопустимое событие: пользователь без роли `ENGINEER` изменяет результат диагностики.

## Внешний источник
Не использован.

## Приоритет
High

Подмена результата диагностики может привести к неверному ремонту и передаче клиенту ложной информации.
