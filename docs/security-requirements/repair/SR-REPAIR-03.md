# SR-REPAIR-03

## Утверждение
Назначать, изменять и удалять услуги и необходимые компоненты до фиксации согласия или отказа клиента может только аутентифицированный пользователь с ролью `ENGINEER`.

## Критерий приёмки
- Пользователь с ролью `ENGINEER` назначает, изменяет или удаляет услугу либо необходимый компонент до решения клиента: сервис выполняет операцию и увеличивает версию предложения.
- Пользователь с ролью `ENGINEER` пытается изменить услуги или компоненты после согласия или отказа клиента: сервис возвращает ошибку текущего состояния и не изменяет данные.
- Пользователь с ролью `CLIENT`, `ADMIN` или `SUPERUSER` без роли `ENGINEER` пытается назначить, изменить или удалить услугу либо компонент: сервис возвращает ошибку доступа.
- Неаутентифицированный пользователь обращается к сервису изменения услуг или компонентов: сервис возвращает ошибку аутентификации.

## Внутреннее обоснование
- Актив: состав услуг и перечень компонентов для ремонта.
- Роль: инженер, клиент, сотрудник.
- Взаимодействие: назначение, изменение и удаление услуг и компонентов.
- Недопустимое событие: пользователь без роли `ENGINEER` изменяет состав ремонта.

## Внешний источник
Не использован.

## Приоритет
High

Несанкционированное изменение состава ремонта может привести к выполнению неверных работ, расходованию компонентов и изменению итоговой стоимости.
