# SR-REPAIR-05

## Утверждение
Пользователь с ролью `CLIENT` может просматривать результаты диагностики, состав ремонта, стоимость, ожидаемое время и состояние только собственных заявок.

## Критерий приёмки
- Пользователь с ролью `CLIENT` запрашивает сведения о принадлежащей ему заявке: сервис возвращает сведения о диагностике и ремонте этой заявки с кодом `200 OK`.
- Пользователь с ролью `CLIENT` запрашивает сведения о чужой или несуществующей заявке: сервис возвращает одинаковый ответ `404 Not Found` и не раскрывает сведения о заявке или владельце.
- Неаутентифицированный пользователь запрашивает сведения о заявке: сервис возвращает `401 Unauthorized` и не раскрывает сведения о ее существовании.

## Внутреннее обоснование
- Актив: результаты диагностики, состав ремонта, стоимость, ожидаемое время и состояние заявки.
- Роль: клиент-владелец заявки, другой клиент.
- Взаимодействие: просмотр сведений о диагностике и ремонте.
- Недопустимое событие: клиент получает сведения о чужой заявке.

## Внешний источник
Не использован.

## Приоритет
High

Получение данных чужой заявки раскрывает персональные, технические и финансовые сведения другого клиента.
