# SR-REPAIR-05

## Утверждение
Пользователь с ролью `CLIENT` может просматривать результаты диагностики, состав ремонта, стоимость, ожидаемое время и состояние только собственных заявок.

## Критерий приёмки
- Пользователь с ролью `CLIENT` запрашивает сведения о принадлежащей ему заявке → сервис возвращает сведения о диагностике и ремонте этой заявки.
- Пользователь с ролью `CLIENT` запрашивает сведения о заявке другого клиента → сервис возвращает ошибку доступа.
- Неаутентифицированный пользователь запрашивает сведения о заявке → сервис возвращает ошибку аутентификации.

## Внутреннее обоснование
- Актив: результаты диагностики, состав ремонта, стоимость, ожидаемое время и состояние заявки.
- Роль: клиент-владелец заявки, другой клиент.
- Взаимодействие: просмотр сведений о диагностике и ремонте.
- Недопустимое событие: клиент получает сведения о чужой заявке.

## Внешний источник
Не использован.

## Приоритет
High

Получение данных чужой заявки раскрывает персональные, технические и финансовые сведения другого клиента.
