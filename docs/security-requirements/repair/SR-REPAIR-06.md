# SR-REPAIR-06

## Утверждение
Подтвердить или отклонить ремонт может только аутентифицированный пользователь с ролью `CLIENT`, которому принадлежит заявка.

## Критерий приёмки
- Пользователь с ролью `CLIENT` подтверждает или отклоняет ремонт по собственной заявке → сервис фиксирует выбранное решение.
- Пользователь с ролью `CLIENT` пытается подтвердить или отклонить ремонт по заявке другого клиента → сервис возвращает ошибку доступа.
- Пользователь с ролью `ENGINEER` или `EMPLOYEE` пытается подтвердить или отклонить ремонт вместо клиента → сервис возвращает ошибку доступа.
- Неаутентифицированный пользователь пытается принять решение по заявке → сервис возвращает ошибку аутентификации.

## Внутреннее обоснование
- Актив: решение клиента о проведении ремонта.
- Роль: клиент-владелец заявки, другой клиент, инженер, сотрудник.
- Взаимодействие: подтверждение или отклонение ремонта.
- Недопустимое событие: решение по заявке принимает не её владелец или сотрудник вместо клиента.

## Внешний источник
Не использован.

## Приоритет
High

Решение клиента является основанием для начала ремонта и возникновения связанных с ним расходов.
